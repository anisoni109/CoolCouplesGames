Game Rules

Feedback Meaning (Custom):

  • **Pos (Correct Positions):** This is the number of digits in your guess that are **correct** and in the **exact right position** (like "Bulls" in Mastermind).
  • **Num (Total Correct Digits):** This is the **TOTAL number** of unique digits in your guess that are present anywhere in the secret number.

*A winning guess will show: Pos = [Total Digits] and Num = [Total Digits].

Settings:

The game requires guessing a secret number of a set number of digits (e.g., 4). Repetition can be turned **ON** or **OFF** (requiring unique digits).
